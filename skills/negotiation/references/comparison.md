# 두 접근의 비교·결합 — Voss vs Ury

| 축 | Chris Voss (전술적 공감) | William Ury (원칙 협상) |
|---|---|---|
| 출발점 | **감정** — 모든 결정엔 감정 | **이해관계** — 입장 뒤의 동기 |
| 인간관 | 상대는 "감정이 격해진 자기 자신" | 최대 장애물은 나 자신 |
| 핵심 동사 | 라벨링·요약·유형 읽기 | 발코니·리프레임·다리 놓기 |
| 대표 도구 | Labeling, "That's right", 교정질문, No, 블랙스완 | 이해관계 발굴, BATNA, 골든 브릿지 |
| 층위 | 톤·심리의 미시 조작 | 구조·프레임의 거시 설계 |

## 일치하는 지점 (많다)
- **경청이 최고의 힘.** 둘 다 협상을 말하기가 아닌 듣기로 정의.
- **입장 뒤 진짜 욕구를 파라.** Voss의 라벨링 = Ury의 창문·자유 이야기. Voss도 "더 나은 것을
  놓치지 마라"로 이해관계 우선을 인정.
- **관계를 파괴하지 마라.** Voss "hammer 금지" = Ury "존엄·positive no". 일회성 거래는 없다.
- **감정·존엄이 결정을 좌우.** Voss의 "fear of loss" = Ury의 "실패자로 보일 두려움".

## 상충/강조점 차이
- **"Why" 논쟁(가장 실질적 전술 충돌)**: Ury는 **"왜(why)"**를 이해관계 발굴의 마법 질문으로
  쓰지만, Voss는 "Why"가 방어를 부른다며 **"How/What"**을 선호.
- **미시 vs 거시**: Voss는 톤·단어·3초 침묵의 실시간 심리전, Ury는 준비·구조·프레임 설계.

## 결합 방법 (실무 권장)
1. **준비 = Ury**: 내 이해관계·상대 이해관계·BATNA·객관적 기준을 정의, 발코니 세팅.
2. **테이블 = Voss**: 어큐제이션 오딧으로 시작→긴장 완화, 라벨링·미러링·교정질문으로 이해관계와
   블랙스완을 끌어냄. "That's right"를 돌파구로.
3. **마무리 = Ury**: 발굴한 이해관계로 상호이익 옵션, positive No로 선을 지키고, 골든 브릿지로
   상대가 체면을 지키며 합의.

## 언제 무엇을
- **Voss식**(감정·전술): 감정 격앙·비이성적 상대·정보 비대칭 큰 상황(M&A 초기 탐색, 위기 대응).
- **Ury식**(원칙·구조): 복잡한 다자·장기 관계·명분 중요(M&A 구조 설계, 노사·JV, 분쟁 종결).
- **대부분의 실전 = Ury의 뼈대 위에 Voss의 전술.**
