## 수집 방법 (2026-07)

1. **YouTube Data API**(MCP 커넥터)로 채널 영상 목록 100개+를 수집하고, 그중
   UIUX 강의성 영상 54개를 선별해 **영상 설명란 전문**을 수집했다.
   마디아는 각 쇼츠/영상의 설명란에 해당 영상의 핵심 교훈을 직접 서술한다 —
   이 텍스트가 스킬의 1차 근거이며 `references/madia-quotes.md`에 원문으로 보존했다.
2. **자막(자동 생성 스크립트) 48편** — 쇼츠·강의 40편과 10~20분 장편 컨펌 영상 8편
   (커머스 주문서/메인, 온보딩, 라인 컨셉, 배너 그래픽, 컨셉 웹, 반응형 웹, 금융 앱) —
   을 수집해 실제 발언(구체 수치, 반복 지적 패턴, 방법론)을 추출했다
   → `references/confirm-patterns.md`, `references/career-portfolio.md`.
   공식 YouTube API의 자막 다운로드는 소유자 전용이라 웹 플레이어용 자막 엔드포인트로
   수집했다.
3. 채널 RSS 피드, madia.co.kr, 패스트캠퍼스 커리큘럼 등 공개 자료로 보강했다.

## 정리 방식에 대한 주의

- 인용문은 영상 설명란에 마디아가 직접 쓴 텍스트다 (가독성을 위해 오타·띄어쓰기 일부 정돈).
- `confirm-patterns.md`의 수치는 자막에서 확인된 마디아의 실제 발언이다. 다만 자동
  생성 자막 특성상 표기 오차 가능성이 있고, 특정 시안 맥락에서 나온 값이므로
  절대 규칙이 아니라 기본값(디폴트)으로 취급한다.
- SKILL.md의 일부 수치(4/8 배수 간격, 텍스트 컬러 3계층 등)는 원칙을 실행 가능하게
  만들기 위해 업계 표준 실무 관행으로 보강한 값이다.
- 마디아의 디자인 파일·강의는 유료 저작물이므로, 이 스킬은 공개된 교훈 텍스트의
  요약·재구성에 한정한다.
