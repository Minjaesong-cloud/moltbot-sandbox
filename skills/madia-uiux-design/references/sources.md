# 출처 및 수집 방법

이 스킬은 유튜브 채널 **Madia Design** (마디아, https://www.youtube.com/@UXUIDesign,
채널 ID `UCxRnfrmJAkRLarzeBJETB5g`)의 공개 콘텐츠를 기반으로 정리한 것이다.

- 마디아: 실무 11년차 UIUX 디자이너. 구독자 약 22.8만, 영상 500개 이상 (2026-07 기준).
- 공식 사이트: https://madia.co.kr
- 패스트캠퍼스 강의: "마디아의 UX/UI 포트폴리오 심폐소생술 올인원 패키지"

## 수집 방법 (2026-07)

1. **YouTube Data API**(MCP 커넥터)로 채널 영상 목록 100개+를 수집하고, 그중
   UIUX 강의성 영상 54개를 선별해 **영상 설명란 전문**을 수집했다.
   마디아는 각 쇼츠/영상의 설명란에 해당 영상의 핵심 교훈을 직접 서술한다 —
   이 텍스트가 스킬의 1차 근거이며 `references/madia-quotes.md`에 원문으로 보존했다.
2. 자막(스크립트) 다운로드는 YouTube API 정책상 영상 소유자만 가능해 사용하지 못했다.
3. 채널 RSS 피드, madia.co.kr, 패스트캠퍼스 커리큘럼 등 공개 자료로 보강했다.

## 정리 방식에 대한 주의

- 인용문은 영상 설명란에 마디아가 직접 쓴 텍스트다 (가독성을 위해 오타·띄어쓰기 일부 정돈).
- 구체 수치(타입 스케일 px, 4/8 배수 간격 등) 일부는 원칙을 실행 가능하게 만들기 위해
  업계 표준 실무 관행으로 보강한 값이며, 해당 부분은 마디아 본인의 발언이 아니다.
- 마디아의 디자인 파일·강의는 유료 저작물이므로, 이 스킬은 공개된 교훈 텍스트의
  요약·재구성에 한정한다.
