# 신용파생 · 스왑 (Patrick Boyle 강의 기반)

## 신용의 기본

- 신용리스크 = 이연지급 약속이 안 지켜질 위험(부도·카운터파티). 부도/상환의 이진 결과를 넘어
  **신용등급 악화·개선의 손익**까지 포함.
- **증권화(Securitization)의 도덕적 해이**: 전통적으로 은행은 대출을 만기까지 보유했으나,
  증권화로 대차대조표에서 떼어내 빠르게 대출을 늘림. **"보유할 의도 없이 대출하면 신용리스크를
  정확히 측정·감시할 유인이 준다"** → 심사비용 최소화 → 신용의 질 저하(2008 위기의 씨앗).

## CDS (Credit Default Swap)

- 기원: Blythe Masters(JP Morgan). 1994년 엑슨 $48억 신용공여의 부도위험을 팔아 규제자본 절감.
  "채권·금리 대신 **부도위험을 스왑**한다."
- 구조: 보장매수자가 정기 **스프레드** 지급 → **신용사건**(파산·미지급·구조조정) 시 매도자가
  액면가로 채권 매입(또는 현금정산). 기초채권 보유 불필요. **개시 시 가치 0**, 이후 손익.
- 참여자: 은행이 최대 매수자(대출장부 헤지), 보험사가 최대 매도자. 대부분 5년.
- **차익거래**: CDS 스프레드 ≈ 채권의 무위험 대비 스프레드. 채권수익 8%·무위험 4%인데 CDS
  300bp면 채권매수+보장매수로 연 1% 무위험 차익.
- 회수율 통상 액면의 30~40%(cheapest-to-deliver). **내재 부도확률**을 CDS 가격에서 역산.
  지수: 미 CDX, 유럽 iTraxx.
- **극단적 페이오프·도덕적 위험**: $1,000만 명목에 연 1~2% 내고 신용사건 시 $1,000만 수령
  → 매우 왜곡된 손익 → 카운터파티 리스크가 핵심 고민.

## CDO (Collateralized Debt Obligation)

- ABS의 일종. 자산 풀의 손실위험을 **트랜치**로 잘라 다른 투자자에게 판매(최초 1987 Drexel).
- **트랜치(변제순위)**: Senior AAA → Junior AAA → AA → A → BBB → Residual(equity, "독성폐기물").
  손실은 최하위부터 흡수, 현금흐름은 최상위부터. 위험↑ = 쿠폰↑.
- 목적: 평균 품질 채권으로 AAA(수요 많음)를 만들어냄. **"저질 햄버거로 안심 스테이크를 만들 순
  없다"**(garbage in, garbage out).
- 위기로의 진화: 서브프라임 MBS 하위 트랜치를 재차 묶은 CDO, CDS 기반 **합성 CDO**, CDO 하위
  트랜치를 또 묶은 **CDO-squared**. 발행 2000년 $690억 → 2006년 ~$5,000억.
- **상관관계가 핵심**: 상관 낮으면 시니어 안전·주니어 위험. **상관 높아질수록 시니어가 더
  위험**해지고 완전상관이면 시니어·주니어가 똑같이 위험. **위기 때 부도가 동조화(상관 상승)** →
  저상관·분산 가정이 무너진다. 물리학자 모델의 상관·부도확률이 현실과 크게 어긋남.

## 스왑 (Swaps)

- 본질: 두 갈래 현금흐름 교환. 보통 **개시 시 가치 0**(양쪽 현가 동일), 이후 시장변화로 손익.
  제로섬. **"스왑 가치 = 받는 현금흐름 현가 − 지급 현금흐름 현가. 채권을 프라이싱할 수 있으면
  스왑도 프라이싱할 수 있다"**(BS·확률미적분 불필요).

**FRA(선도금리계약)**: 미래 특정 기간에 대해 오늘 합의한 금리로 차입/대여. 제로쿠폰 채권에서
내재 선도금리 역산. 예: 2년 뒤 6개월 3.5% 약정, 실제 4%면 차액 6개월분 현가만큼 손실.

**금리스왑**: 고정 vs 변동(LIBOR) 교환, **명목원금 미교환**(계산 기준일 뿐). 평가 2방법:
①고정채권 vs 변동채권 차이 ②FRA 포트폴리오(동일 결과). 변동채권은 다음 쿠폰일에 액면으로
리셋되므로 다음 쿠폰만 할인. 용도: 조달금리 전환(변동→고정으로 30년 고정대출 공급), 금리 투기,
**비교우위 활용**(각자 유리한 시장에서 빌려 스왑, CFA 단골).

**통화스왑**: 차입 통화 전환. **명목원금을 개시·만기에 교환**(다른 통화라서). 예: BMW가 유로로
빌려 달러로 스왑. 평가: 자국통화 수취가치 = 자국채권가 − 현물환율×외국채권가.

**기타**: 주식(총수익)스왑(집중 보유주식을 세금 없이 분산), 상품스왑, **변동성/분산 스왑**
(표준편차는 √때문에 헤지 어려워 분산 기반), 배당스왑, 스왑션.

## 2008 위기와의 연결 · 규제

- 증권화가 심사·감시 유인을 약화 → 신용의 질 저하. CDS가 리먼·AIG 붕괴를 가속.
- **보험대상 이익(insurable interest) 없는 보험**은 사회적 차선 유발 — 채권+CDS 보유자가 부도를
  유도할 유인. "insurable interest 없는 보험은 규제·불법화되어야 한다는 주장."
- 그리스(2012): 75% 상각이 법에 의한 것이라 처음엔 신용사건 불인정 → CDS 무용론이 시장을
  파괴할 뻔했으나 ISDA가 결국 신용사건 판정.
- 규제: Dodd-Frank로 스왑을 CFTC·중앙청산소(ICE Clear Credit, CME)로 이동. 단일종목 CDS는 여전히
  양자거래 → 자본부담↑, 투자은행 이탈, 거래비용 상승.

## 관통하는 경고

- **"위험이 비슷한데 수익이 높다"는 경계 신호** — CDO가 동급 회사채보다 2~3%p 높다면 힌트.
- **모델 리스크**: 위기에는 부도·상관이 동조화되어 분산 가정이 무너진다.
- **카운터파티 리스크**가 OTC 파생의 핵심(중앙청산으로 이동 중이나 미완).
