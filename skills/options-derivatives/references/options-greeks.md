# 옵션 기초 · 그릭스 · 프라이싱 (Patrick Boyle 강의 기반)

## 옵션 기초

- 옵션 = 미래 특정 시점(만기)에 특정 가격(행사가)으로 거래할 **권리(의무 아님)**. 매수자는
  유리할 때만 행사 → 매도자에게 프리미엄 지급.
- **콜**: 살 권리(매수자 강세). **풋**: 팔 권리(매수자 약세). 매수자 1명당 매도자 1명, 반대 견해.
- **미국식**(만기 전 언제든 행사, 가장 많이 거래) vs **유럽식**(만기일만, 계산이 가장 쉬움).
  동일 조건이면 미국식이 더 비싸다(추가 행사 자유).
- **손익 비대칭**: 매수자 최대손실=프리미엄, 상방(콜)은 이론상 무한. 매도자 최대이익=프리미엄,
  네이키드 매도 손실은 무한 → 마진 필요.
- **가치 = 내재가치 + 시간가치**. 만기가 길수록 비싸다(큰 이동이 일어날 시간이 많음).

## 그릭스 (민감도 = 편미분)

**델타(1차)** — 기초자산 가격 변화에 대한 옵션가격 민감도. 기초자산 자체 델타=1.
- 그릭스는 선형 합산된다. 예: 200주 숏 + 델타0.5 콜 5계약 롱 + 델타−0.2 풋 2계약 숏
  = −200 + (5×100×0.5) + (−2×100×−0.2) = **순델타 +90** (90주 롱과 동일 노출).
- 작은 움직임의 선형 근사 → 큰 변동엔 부정확(감마 필요).

**감마(2차)** — 델타의 변화율(BS를 기초가로 2번 미분). 롱 옵션=+감마, 숏 옵션=−감마.
- **등가격에서 최대**, 내가격/외가격으로 갈수록 작아짐. 만기 임박 시 등가격 감마 급증.
- 델타뉴트럴=작은 움직임 방어, 감마뉴트럴=리밸런싱 사이 큰 움직임 방어. 감마↑ = 잦은 재헤지.

**세타** — 시간가치 감쇠(time decay). 보통 1일 세타. 롱 옵션은 매일 가치 감소, 숏은 유리.
- **헤지 불가.** "시간감쇠가 싫으면 옵션을 사지 마라."

**베가** — 내재변동성(IV) 민감도(IV 1% 변화당). **콜·풋 둘 다 변동성 상승 시 가치 증가**
= 롱 옵션 = 롱 볼. 이것을 이해하는 것이 옵션 이해의 핵심. 스트래들·스트랭글이 특히 민감.

**로** — 금리 민감도(만기 동일 시에만 합산 가능).

## 중립 포트폴리오 구성

- 주식+옵션 1개로는 델타뉴트럴은 되지만 **감마뉴트럴 불가** → 헤지할 그릭스마다 옵션 1개씩 추가.
- **모든 그릭스 완전 헤지는 현실에서 사실상 불가능**(적절한 옵션 부재, 유동성·거래비용).
- 실무: 하루 1~2회 델타 평탄화, 나머지는 모니터링. 베가·반나·볼가는 변동성 곡면 때문에 단순
  합산이 어렵다.

## 프라이싱

- **Black-Scholes-Merton**: PDE 기반 폐형해. 핵심 가정 "변동성 일정"은 현실과 어긋나며 이
  괴리가 베가 노출의 원천. **강점: 공정가 + 복제(헤지) 전략까지 제시.**
- **내재변동성**: 옵션 가격은 사실상 변동성으로 결정. 프라이싱의 본질 = 변동성 추정.
- **변동성 스마일/스큐**: 행사가·만기마다 IV가 다르다. 시장이 예상보다 크게 움직이면
  스마일 밖으로 벗어나 헤지가 무너진다(신용위기 때 바클레이즈 분산스왑 중단).
- **몬테카를로**(Phelim Boyle 1977): 이론 대신 수천 개 경로를 시뮬레이션해 평균 페이오프를
  무위험할인. 정확도는 반복횟수의 √에 반비례. 변수 3개↑(경로의존·바스켓·레인보우)일 때 사용.
  **한계**: 최후의 수단. 분포·점프 가정에 의존, 조기행사 처리 난망(LSM 필요), **헤지 전략을
  주지 못함** → 몬테카를로로만 값매기는 옵션은 헤지가 어려워 매도자가 비싸게만 판다.

## 옵션 마진

- 선물과 달리 **매도자만** 마진(매수자는 프리미엄이 최대손실).
- **커버드 매도**(기초자산 보유)는 마진 낮고, **네이키드 매도**는 높다.
- 초기 마진 vs 유지 마진, 유지 아래로 떨어지면 마진콜 → 당일 미납 시 강제청산.
- **변동성이 오르면 기초자산이 제자리라도 추가 마진** 요구.
