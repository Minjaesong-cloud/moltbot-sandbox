# 투자·금융 스킬 인덱스

유튜브 전문가 강연·강의를 추출·구조화해 만든 투자/금융 스킬 모음의 지도. 어떤 질문에 어느
스킬이 뜨는지와 스킬 간 연결을 정리한다. (디자인 스킬 `madia-uiux-design`은 별도.)

## 스킬 지도

### 1. `hedge-quant-strategies` — 헤지펀드·퀀트 전략 허브
전략 지형과 실무 지혜의 중심. **트리거**: 헤지펀드·퀀트·아비트라지·팩터·트렌드추종·시장중립·
롱숏·매크로·리스크패리티·전략 평가·펀드 DD.
- **전략 카탈로그**: 8대 패밀리 55개 전략(수익원·손익구조·리스크·캐파).
- **계열 심화**: 헤지펀드전략·퀀트·팩터·행동재무학·트렌드추종/CTA·변동성·구조화크레딧·
  멀티전략·스탯아브·크립토·이머징매크로·액티비스트·실패사례.
- **전문가 8명**: Patrick Boyle(전략 메커니즘) · Ben Felix(팩터·인덱스) · Ray Dalio(매크로·
  부채사이클) · Aswath Damodaran(밸류에이션) · Robert Carver(시스템 트레이딩) · Howard
  Marks(사이클·디스트레스트·리스크) · Joel Greenblatt(특수상황) · Stanley Druckenmiller(매크로·집중).
- **워크드 예제**로 툴킷을 실전에 엮는 법.

### 2. `options-derivatives` — 옵션·파생상품
**트리거**: 옵션·그릭스·델타·감마·변동성·스왑·CDS·CDO·구조화상품·헤지·파생.
- 이론(Boyle): 그릭스·프라이싱·구조화상품·이색옵션·신용파생·스왑.
- 실전(Sinclair·Eifert): VRP·옵션 엣지·숏볼 관리·딜러 감마·디스퍼전·시장 구조.

### 3. `financial-statement-analysis` — 재무제표 분석·부정 탐지
**트리거**: 재무제표·이익의 질·발생액·분식·회계 부정·레드 플래그·현금흐름·DD 재무.
- 회계 조작 수법 · 레드 플래그 체크리스트 · Beneish M-score · 이익의 질(현금 검증).
- 전문가: Howard Schilit, Marcellus, Beneish.

### 4. `industry-analysis` — 산업·섹터 분석
**트리거**: 산업·업종·섹터 분석·비교·유망 섹터·경쟁강도·산업 밸류에이션.
- 실측(Damodaran 96산업 마진·ROE·베타·자본비용) × 검증 프레임(생애주기·경기민감도·해자)
  × 전문가 렌즈(Damodaran·Marks·Dalio·Greenblatt). `industry_profile.py <산업>` 즉시 실행.
- **제1원칙**: 근거 없는 "산업 전문가 견해"를 지어내지 않고 실측+프레임+실제 추출 렌즈만 적용.

## 스킬을 엮는 표준 투자 워크플로

1. **전략 지형 파악** — 어떤 전략인가·어떻게 돈 버나·어떻게 죽나 → `hedge-quant-strategies`(카탈로그·5단계 프레임).
2. **숫자 검증** — 이익이 현금으로 뒷받침되나, 조작 신호는 → `financial-statement-analysis`.
3. **가치 추정** — 검증된 숫자로 가치 vs 가격 → `hedge-quant-strategies`(Damodaran).
4. **사이클·촉매·심리** — 지금 사이클 어디, 촉매 있나 → Marks·Greenblatt·Dalio·Druckenmiller.
5. **파생·헤지 설계** — 옵션으로 비대칭·헤지 → `options-derivatives`.
6. **리스크·사이징·분산** — 어떻게 죽는가·스큐로 분산·절반 샤프 사이징 → 실패사례·Carver·스큐 지도.

## 관통하는 공통 원칙 (전문가 교차 검증)

- **분산이 유일한 공짜 점심** (Carver·Marks·Dalio). 단, 진짜 분산은 개수가 아니라 **스큐의
  상보성**(음의 스큐 + 양의 스큐).
- **리스크 = 변동성이 아니라 영구적 자본 손실** (Marks·Greenblatt·Druckenmiller). 생존이 복리의 전제.
- **"이익은 의견, 현금은 사실"** (Schilit) + **"가격 ≠ 가치"** (Damodaran·Marks) — 숫자와 가치를
  분리해서 본다.
- **감정을 배제한 사전 규칙·겸손** (Carver·Druckenmiller·Felix). "틀렸을 때 마음을 바꾼다."
- **"위험이 비슷한데 수익이 높다"·"매끈한 수익"은 경계 신호** (Boyle·Eifert·Marks). 숨은
  꼬리·레버리지·모델 리스크.

## 제작 방식 (재현 가능)

각 스킬은 유튜브 전문가 채널/강연의 자막을 yt-dlp로 수집 → 서브에이전트로 인사이트 추출 →
구조화·관점 대조 후 스킬화했다. 새 전문가를 추가할 때는 기존과 대조해 **일치=공통 원칙,
상충=관점 차이(상황별 기준)** 로 정리하는 허브 구조를 따른다(각 스킬 SKILL.md 참조).
