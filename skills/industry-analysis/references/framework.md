# 산업 분석 프레임워크 — 무엇을 보고, 전문가 렌즈를 어떻게 적용하나

실측 숫자(Damodaran 96산업)를 구조적 판단으로 바꾸는 프레임. 전부 검증된 분석틀이며,
"전문가가 이렇게 말한다"를 지어내지 않는다.

## 1. 다섯 개의 구조 질문 (실측 숫자로 답한다)

| 질문 | 실측 지표 | 판정 기준 |
|---|---|---|
| **경기민감도** — 사이클 타는가 | 베타 | ≥1.2 경기순환주 / ≤0.8 방어주 |
| **가치창출** — 자본비용을 버는가 | ROE − WACC | >+3%p 해자 가능 / <−2%p 구조적 열위 |
| **마진 구조** — 무엇으로 버는가 | 매출총이익률·순이익률 | ≥50% 차별화·IP / ≤25% 원가경쟁 |
| **생애주기** — 어디쯤인가 | 적자기업비율·PER | 적자 다수·초고PER 성장초기 / 저PER 성숙 |
| **밸류에이션** — 프리미엄이 정당한가 | PBV vs ROE | PBV ≈ (ROE−g)/(CoE−g) 정당화 여부 |

## 2. 전문가 렌즈 (실제 추출된 프레임을 산업 숫자에 적용)

`hedge-quant-strategies/references/experts/`에서 실제 소스로 추출한 프레임을 산업 층위로.

- **Damodaran (밸류)**: "가격 ≠ 가치." PBV·PER 프리미엄이 ROE·성장으로 정당화되는가.
  고PBV인데 저ROE = 성장 기대 or 과열. 생애주기별로 밸류 방법이 다르다(성장초기는 스토리,
  성숙은 현금흐름, 쇠퇴는 청산가치).
- **Marks (사이클)**: "우리가 어디 있는지 알 수 없어도, 어디쯤인지는 안다." 경기순환 산업
  (고베타)은 **사이클 위치가 진입의 전부** — 바닥 비관에서 사고 정점 낙관에서 판다.
  방어산업은 사이클보다 개별 해자·규제가 관건.
- **Dalio (매크로)**: 부채사이클·금리·유동성 국면. 고베타 산업은 긴축에 취약, 실질금리 민감.
- **Greenblatt (특수상황·구조)**: 자본비용 잠식 산업(ROE<WACC)의 "싸 보임"은 함정일 수
  있다 — 평균회귀 베팅 전에 구조적 열위인지 일시적 부진인지 구분.
- **Druckenmiller (집중·유동성)**: 산업의 방향이 확실할 때 집중, 유동성이 밀어주는 섹터.

## 3. 데이터 함정 (실측에서 확인)

- **금융업 매출총이익률 100%**: 은행·보험은 매출원가 개념이 없어 무의미. 금융은 ROE·순이자
  마진·대손·자본비율로 본다(매출총이익률 무시).
- **적자기업 생존편향**: PER은 흑자기업만으로 계산 → 적자비율 높은 산업(바이오 62%)의 PER은
  생존자 편향. 적자비율을 반드시 함께 볼 것.
- **음(−)의 장부가 → PBV 왜곡**: 자사주 매입 큰 산업의 PBV 극단값은 산술 왜곡(DAMODARAN-SCREENER.md).
- **미국 기준**: Damodaran은 미국 상장사 평균. 한국·신흥국 산업에 쓸 땐 국가 ERP(damodaran.erp)
  더하고 회계·지배구조·산업구성 차이 감안. 상대 순위(어느 산업이 고/저마진인가)는 참고 가능.
- **중앙값 대비 배율**: 프로파일러의 "×시장"은 96산업 중앙값 대비. 절대 판단이 아니라 위치.

## 4. 한국 산업에 적용할 때

- Damodaran(미국)으로 산업의 **구조적 성격**(경기민감·마진·자본집약)을 잡고,
- **실제 한국 수치**는 DART(재무)·Naver(주가)로 개별사 집계 → `hedge-quant-strategies`의
  한국 팩터 파이프라인. 예: 한국 반도체(삼성전자·하이닉스)는 글로벌 반도체 구조(고베타·
  고마진·사이클)를 공유하되 밸류에이션·배당·지배구조는 한국 디스카운트 반영.
- 국가 리스크 프리미엄: `damodaran.erp('Korea')` = 4.87%(할인율 입력값).

## 5. 산업 비교·유망 섹터 판단

여러 산업을 나란히: `industry_screener()`(damodaran.py) 전체 표에서
- **가치창출 상위**(ROE−WACC 큰) = 구조적으로 좋은 사업
- **저평가 후보**(PBV 낮은데 ROE 유지) = "왜 싼가" 질문 대상
- **사이클 저점**(고베타 산업이 침체 국면) = Marks식 역발상 후보
단, 산업 매력 ≠ 진입 타이밍. 사이클·매크로(Marks·Dalio)와 결합해 판단.
