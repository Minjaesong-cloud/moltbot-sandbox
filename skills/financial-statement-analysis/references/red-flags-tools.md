# 레드 플래그 체크리스트 + 정량 탐지 도구

## 레드 플래그 체크리스트

**지배구조·인적**
- 원맨쇼(오너 1인 좌우), 이사회에 친인척·지인 포진(질문 못 하는 이사회).
- 관계자거래(related-party) 과다 — 상장사에서 비상장 계열사로 자금 이전 통로.
- 프로모터 지분 담보대출(pledging) 높음.

**회계·감사**
- 감사인 교체, 특히 무명·소규모 감사인. 자회사를 주감사인이 아닌 다른 감사인이 감사(책임 분산).
- 회계정책·추정의 잦은 변경(감가·충당금). **연결 vs 별도** 재무제표 차이가 큼 → 반드시 연결로.
- 계열사 많고 지분·거래가 복잡(불투명 그룹 구조). 배당은 선언하나 이익이 현금으로 뒷받침 안 됨.

**대차대조표·손익**
- **매출채권 급증**(매출 증가율 초과, DSO 상승). **재고 급증**·재고회전 악화.
- **CWIP 과다·장기 정체**. 우발부채가 순자산 대비 큰 비중(BS 밖 위험).
- 매출총이익률·순이익률이 업계 대비 비정상적으로 높거나 급변. (금융사) 이자수익률이 비정상 고.
- **영업현금흐름과 순이익의 지속적 괴리**, 자유현금흐름 마이너스 지속.

**정성 검증(1차 데이터)**
- 공급업체·딜러·전직원 등 제3자 확인(channel checks)으로 숫자 뒤 실체 파악.
- 영업 인센티브 구조 — "회수"가 아닌 "매출"에만 연동되면 밀어내기 유인.

## Beneish M-Score (8변수)

전제: **고성장 + 마진 악화 + 판관비 상승** 기업일수록 조작 유인. 8개 비율에 가중계수를 곱해 합산.
1. **DSRI** 매출채권회수기간지수 — 매출채권이 매출보다 빨리 늘면 매출 조기·과대인식.
2. **GMI** 매출총이익률지수 — 마진 악화 시 조작 유인↑.
3. **AQI** 자산품질지수 — 비유동·무형 비중↑ → 비용 자본화 의심.
4. **SGI** 매출성장지수 — 고성장 자체가 압력.
5. **DEPI** 감가상각지수 — 상각률 낮춰 비용 이연.
6. **SGAI** 판관비지수. 7. **LVGI** 레버리지지수. 8. **TATA** 총발생액/총자산 — 이익이 현금
   아닌 발생액으로 구성될수록↑.

**판정**: M-Score > **−2.22** 면 조작 가능성 있음(정밀조사 대상), < −2.22면 낮음.
- 초과는 "조사 대상"이지 유죄 확정이 아니다(실무 예: −1.6은 회계오류였고, +2.1은 실제 부정).
- **거시 활용**: 시장 전체에 적용 시 통상 ~3%가 신호, 이 비율이 **5%를 넘으면 이듬해 침체
  경향**(실적 압박에 조작이 늘기 때문).

## 발생액·비율 스크리닝

- **총발생액 = 순이익 − 영업현금흐름.** 총자산 대비 비율이 높고 상승세면 이익의 질 저하
  (Sloan accrual anomaly: 발생액 높은 기업이 이후 부진). M-Score의 TATA와 동일 원리.
- **비율분석**: 이익률(첫 관문 — 큰 변동은 즉시 조사), 유동비율·부채비율·ROE 등을 동종업계·
  과거 추세와 비교. **비율분석 + M-Score를 제대로 병행하면 부정의 ~95% 포착**(강연 주장).
- **스크리닝 전략(Marcellus)**: 회계품질 점수로 유니버스에서 **저품질을 먼저 걸러내고(약 1/3
  제거)** 남은 것만 심층 분석. "Eliminate first, then investigate." 회계품질 하위 종목은 장기
  심각한 부(-)의 수익 → **문제 공개 전에 회피**가 최선의 방어.
