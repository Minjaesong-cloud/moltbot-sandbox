# 워크드 예제 — 재무제표 레드 플래그를 실전에 적용하는 법

이 스킬의 도구(워크플로·이익의 질·레드 플래그·M-score)를 하나의 흐름으로 적용하는 예제.
모든 숫자·상황은 방법을 보여주기 위한 **예시**이며 특정 기업 판정이 아니다.

## 예제 — "이 고성장 기업의 이익을 믿어도 될까?"

**상황(가정)**: 3년간 매출 +25%/년, 순이익 +30%/년으로 화려하다. 시장은 열광한다.

### ① 인센티브 파악
- 곧 상장/증자 예정이고 경영진 보너스가 EPS에 연동. **이익을 좋게 만들 유인이 분명** → 가장
  비판적으로 읽어야 할 상황(Schilit: "매출은 느는데 마진이 얇아질 때 조작 유인이 크다").

### ② 이익 vs 현금 (가장 강력한 렌즈)
- 순이익은 3년간 +30%/년인데 **영업현금흐름(CFO)은 정체 또는 감소** → 발생액(순이익−CFO)이
  매년 커진다. **이익의 질 저하 1순위 신호.** "Earnings are an opinion, cash is a fact."
- 자유현금흐름(FCF)이 수년째 마이너스인데 이익만 증가 → 심각한 경고(강연 사례와 동일 패턴).

### ③ 대차대조표 항목의 증가 속도
- **매출채권이 매출보다 빠르게 증가**(DSO 상승) → 채널 밀어내기·조기인식 의심.
- **재고 급증**·회전 악화, 또는 **CWIP(건설중자산)가 완공 없이 수년째 증가** → 비용을 자산 뒤에
  숨겼을 가능성.
- 무형자산·영업권 급증 → 비용 자본화·부실 인수 의심.

### ④ 회계정책·거버넌스
- 감가 방법·충당금 정책 변경, 관계자거래 증가, 감사인 교체(특히 무명 감사인), 연결 vs 별도
  재무제표 차이 → 각각 별도 조사 항목.

### ⑤ 정량 스크린 (M-score)
- DSRI(매출채권↑)·SGI(고성장)·GMI(마진 악화)·TATA(발생액↑)가 동시에 높으면 **M-score가
  −2.22를 초과** → "정밀조사 대상". (단, 초과는 유죄가 아니라 조사 신호 — 회계오류일 수도.)

### ⑥ 정성 검증
- 공급업체·딜러·전직원 채널 체크로 "매출이 실제 수요인가"를 확인. 영업 인센티브가 회수가 아닌
  매출 목표에만 연동되는지.

### 종합 판정 (방법)
개별 신호 하나로 단정하지 않는다. 하지만 **② 이익-현금 괴리 + ③ 매출채권 급증 + ⑤ M-score
초과**가 동시에 쌓이면, "화려한 이익"의 상당 부분이 현금이 아닌 발생액·자산 항목으로 만들어지고
있을 위험이 높다 → **밸류에이션 이전에 이익 자체를 조정(정상화)하거나 회피**한다. Marcellus의
"Eliminate first, then investigate" — 이런 종목은 심층 분석 전에 우선 걸러낸다.

## 하이브리드 워크플로 (밸류에이션과 결합)
1. **이 스킬로 숫자를 검증** — 이익의 질이 낮으면 그 이익으로 밸류에이션하지 않는다.
2. **hedge-quant의 Damodaran**으로 정상화 이익·현금흐름 기반 가치 추정.
3. **의심 신호가 크면 숏 후보** — 단, 숏은 구조적으로 불리하고(상승 드리프트) 촉매·타이밍이
   필요하다(Boyle/Greenblatt). "나쁜 회사"라고 바로 숏하지 않는다.

핵심: 이 스킬은 **가치의 전제(숫자)를 지키는 문지기**다. 숫자가 통과해야 밸류에이션이 의미를 갖는다.
