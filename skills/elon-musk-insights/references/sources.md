# 출처 및 수집 방법

## 수집 방법 (정직 기록)

- 웹 검색·페이지 추출로 **공개된 인터뷰·강연·전기·검증 보도**에서 수집. 각 인사이트에 출처를
  달았다. 지어낸 내용은 없다.
- **X/트위터는 자동 수집 불가**(무료 API 폐지·JS 월) → 긴 인터뷰·트랜스크립트 위주로 수집.
  단편 트윗보다 맥락 있는 발언을 우선했다.
- YouTube 자막 직접 다운로드는 이 환경에서 소유 영상만 허용(403)되어, 공개된 **텍스트
  트랜스크립트**(TED·Lex Fridman·Everyday Astronaut·Isaacson 전기)로 대체했다.
- 인용 표기: 원문 확정은 그대로, 2차 요약을 거쳐 문구가 다듬어졌을 수 있는 항목은
  `(표현 재구성 가능성)`으로 표시했다. 최종 인용 시 원본 재확인 권장.

## ⚠️ 균형 유의

이 스킬은 머스크의 **방법론**(제1원리·제조 알고리즘·idiot index)을 도구로 담는다. 그의
모든 판단·발언이 옳은 것은 아니며(노동 강도·AI관·경영 논란 등 비판도 존재), 무비판 추종이
아니라 상황에 맞게 취사선택·검증해 쓴다.
