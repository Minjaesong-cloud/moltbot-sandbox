# Damodaran 산업 상대가치 스크리너 + 국가 ERP

`data/damodaran.py` — NYU Stern Damodaran 공개 데이터셋(무료, 연 1~2회 갱신)을 내려받아
**산업 상대가치 대조표**와 **국가별 ERP**를 만든다. `experts/aswath-damodaran.md`의 프라이싱
규율("멀티플은 항상 펀더멘털 대비"로)을 실행 데이터로 뒷받침하는 모듈.

## 사용법

```python
from damodaran import industry_screener, erp, load_industry, country_erp

s = industry_screener()   # ~96개 산업 × [기업수, PER(현재/포워드), 적자기업비율,
                          #               PBV, ROE, 매출총이익률, 순이익률, 베타, 자기자본비용, WACC, PBV/ROE]
erp('Korea')              # {'총ERP': 0.0487, '국가리스크프리미엄': 0.0064, '디폴트스프레드': 0.0042, ...}
```

파일 캐시: `~/.cache/damodaran/` (환경변수 `DAMODARAN_CACHE`로 변경).

## 어떻게 쓰는가 (Damodaran 규율)

1. **멀티플 차이는 결론이 아니라 질문이다.** 반도체 PBV 13 vs 지역은행 1.1은 "반도체가
   비싸다"가 아니라 "ROE 31% vs 10%, 성장·리스크 차이가 그 격차를 설명하는가"를 묻는 것.
   `PBV/ROE` 컬럼이 1차 근사 대조(PBV ≈ (ROE−g)/(CoE−g) 직관).
2. **개별 기업 심사 절차**: 대상 기업 멀티플 → 같은 산업 행과 비교 → 격차를 ROE·마진·베타로
   설명 시도 → 설명 안 되는 격차만이 잠재적 미스프라이싱(그다음 `financial-statement-analysis`로
   숫자의 질 검증).
3. **한국 기업에 쓸 때**: 미국 산업 평균이므로 직접 비교하지 말고 (a) 할인율에 한국 ERP 4.87%
   적용, (b) 회계기준·지배구조 할인·산업 구성 차이를 정성 감안. 상대 순위(어떤 산업이 고/저
   멀티플인가)는 참고 가능.

## ⚠️ 데이터 함정 (실측에서 확인)

- **음(−)의 장부가 왜곡**: Retail (Building Supply) PBV 132, Restaurant/Dining PBV 75는
  자사주 매입으로 장부 자본이 0 근처/음수인 대형사(홈디포 등) 탓의 **산술 왜곡**이다.
  PBV 극단값은 항상 ROE가 NaN·음수·비정상인지 먼저 확인할 것.
- **적자기업비율** 컬럼: PER은 흑자 기업만으로 계산되므로 적자 비율이 높은 산업(바이오 등)의
  PER은 생존 편향이 있다.
- 시트 구조가 해마다 조금 바뀐다 — `_find_header`(헤더 탐색)와 `_pick`(키워드 컬럼 매칭)으로
  방어하지만, 업데이트 후 첫 실행 때 컬럼 매칭 결과를 눈으로 확인할 것.
- ctryprem의 국가 ERP는 **등급 기반**이 기본(CDS 기반은 별도 컬럼). 등급이 시장보다 늦게
  움직이므로 위기 시 과소평가될 수 있다.

  층위에서, 산업/국가 단위 기대수익 추정에 사용(타이밍 스위치 아님).

  종목을 거르고 → 이 스크리너로 산업 맥락을 부여 → 산업 대비 설명 안 되는 저평가만 후보로.
