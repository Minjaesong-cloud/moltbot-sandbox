# 헤지펀드 데이터 지도 — 무엇을 쓰고, 어떻게 응용하는가

헤지펀드·퀀트가 전략에 쓰는 데이터를 카테고리별로 총정리. 각 항목: **무엇 → 어떻게 응용
(어느 전략) → 대표 벤더(유료) / 무료 대안**. 실제로 이 환경에서 뚫리는 무료 소스와 수집 코드는
`ACCESSIBLE-DATA-INVENTORY.md`·`fetch_data.py` 참조.

핵심 원칙: **데이터가 곧 엣지의 원천**이지만, 데이터 자체보다 **응용(신호화·조합·리스크
관리)**이 승부처다(Carver: "제약은 창의성"). 대체데이터는 대개 **감쇠가 빠르다**(널리 쓰이면 소멸).

---

## 1. 시장·가격 데이터 (Market / Price)

- **무엇**: 주식·ETF·선물·옵션·FX·채권·암호화폐의 시가·고가·저가·종가·거래량·호가(틱/분/일).
- **응용**: 거의 모든 전략의 뼈대. 추세추종·모멘텀(가격 시계열), 페어/스탯아브(공적분), 변동성
  전략(옵션 IV), 마켓메이킹(호가·틱), 리스크패리티(변동성·상관).
- **틱/L2 호가·마이크로구조**: HFT·마켓메이킹의 생명. 체결·주문흐름·큐 위치.
- **벤더(유료)**: Bloomberg, Refinitiv, ICE, Polygon, Databento(틱), Tick Data, OneTick, Kaiko(크립토).
- **무료 대안**: FRED(지수·금리·FX·원자재·VIX), Coinbase/CoinGecko(크립토), GitHub 주가 패널,
  Alpha Vantage/Tiingo(무료 키). ← 뚫림.

## 2. 펀더멘털·재무 데이터 (Fundamentals)

- **무엇**: 재무제표(손익·재무상태·현금흐름), 비율(PER·PBR·ROE·부채), 세그먼트, 주석, 가이던스.
- **응용**: **밸류·퀄리티·수익성 팩터**(factor-investing.md), Damodaran식 DCF·상대가치, 이익의
  질·분식 탐지(M-score, financial-statement-analysis 스킬), 디스트레스트(신용지표).
- **애널리스트 추정치(estimates)**: 컨센서스 EPS, 리비전, 서프라이즈 → 실적발표 후 표류(PEAD),
  리비전 모멘텀 전략.
- **벤더(유료)**: FactSet, S&P Capital IQ, Refinitiv, Bloomberg, Visible Alpha(추정치).
- **무료 대안**: **SEC EDGAR XBRL(미국 전 상장사 재무·공시)** ← 강력히 뚫림. DART(한국),
  simfin, Financial Modeling Prep(무료 키). 한국은 pykrx로 PER·PBR·배당.

## 3. 매크로·경제 데이터 (Macro)

- **무엇**: GDP·인플레·고용·금리·통화량·중앙은행 대차대조표·PMI·소비·주택·무역수지·심리지수.
- **응용**: 글로벌 매크로(Dalio 부채사이클·Druckenmiller 유동성), 자산배분·레짐 스위칭, 캐리,
  이머징 매크로. "언제나 유동성"(Druckenmiller) → 연준 대차대조표·M2 변화율.
- **벤더(유료)**: Bloomberg, Haver Analytics, Macrobond, TradingEconomics.
- **무료 대안**: **FRED**(미국·글로벌 수천 시리즈), **IMF datamapper**, **World Bank**, OECD SDMX,
  ECB SDW, 한국은행 ECOS(무료 키). ← 뚫림.

## 4. 포지셔닝·플로 데이터 (Positioning / Flow) — 헤지펀드 필수

- **CFTC COT(Commitments of Traders)**: 선물시장 투기·상업·딜러 포지션. → 매크로·추세의 과열/
  청산 신호, 캐리 트레이드 혼잡도. ← 무료로 뚫림.
- **13F(기관 보유 공시)**: 분기별 기관 롱 포지션. → 스마트머니 추종·혼잡도(crowding) 분석.
  단 45일 지연·롱만. ← SEC EDGAR로 무료.
- **공매도 잔고(Short Interest)**: 숏 스퀴즈·역발상. FINRA·거래소 공시(격주).
- **옵션 플로·딜러 감마(GEX)**: 딜러 헤징이 가격을 증폭(Eifert). → 감마 익스포저·풋콜비율·
  스큐. 벤더: SpotGamma, CBOE.
- **다크풀·주문흐름**: 기관 대량 체결 탐지. 벤더: 유료.
- **펀드 플로·ETF 자금**: 자산군·섹터 로테이션 신호.
- **무료 대안**: CFTC COT ✅, SEC 13F/submissions ✅, FINRA 공매도(공개), CBOE 풋콜비율(FRED).

## 5. 대체데이터 (Alternative Data) — "남보다 먼저 안다"

HF의 최전선. **감쇠가 빠르고 비싸며 노이즈가 크다.** 핵심은 정합성(백테스트 가능성)·적법성·독점성.

- **위성·항공영상**: 주차장 차량 수(리테일 매출), 원유 탱크 그림자(재고), 농작물·광산·건설.
  → 실적 서프라이즈 선행. 벤더: Orbital Insight, RS Metrics, Planet.
- **신용카드·거래 데이터**: 소비자 지출 → 기업 매출 나우캐스팅(리테일·구독). 벤더: Yodlee,
  Second Measure, Facteus. (개인정보·집계 이슈.)
- **지오로케이션(모바일 위치)**: 매장 방문 트래픽 → 리테일·외식. 벤더: Placer.ai, SafeGraph.
- **웹 스크레이핑**: 이커머스 가격·재고·리뷰, 채용공고(성장·감원), 앱 다운로드·MAU(구독·게임).
  벤더: Thinknum, YipitData, App Annie/data.ai, Similarweb.
- **선박·항공·물류(AIS)**: 유조선·컨테이너 위치 → 원자재·무역·공급망. 벤더: MarineTraffic,
  Kpler, Windward.
- **뉴스·소셜 감성(NLP)**: 뉴스·트위터·레딧·어닝콜 텍스트 → 감성 스코어·이벤트 탐지·토픽.
  → 뉴스 기반 트레이딩, 톤 변화. 벤더: RavenPack, Bloomberg NLP. 무료: **GDELT(글로벌 뉴스
  이벤트)** ✅(5초당 1요청), Wikipedia 조회수, 레딧.
- **공급망·B2B 거래**: 기업 간 관계·의존도 → 전이 리스크. 벤더: FactSet Supply Chain.
- **ESG·논란**: 지속가능성·논란 이벤트. 벤더: Sustainalytics, MSCI ESG.
- **날씨·기후**: 농산물·에너지 수요·보험. NOAA(무료).
- **특허·R&D·고용**: 혁신·인재 이동(LinkedIn 스크레이핑). 벤더: 다수.
- **정치·규제·이벤트**: 예측시장(Polymarket), 로비·의회 거래 공시.

## 6. 레퍼런스·메타 데이터 (Reference / Meta) — 없으면 백테스트가 틀린다

- **구성종목·유니버스 이력**: 지수 편입/퇴출 이력 → **생존편향 제거**(필수). 상장폐지 포함.
- **기업행위(Corporate Actions)**: 배당·분할·합병·상폐 → 총수익·수정주가 계산.
- **분류체계**: 섹터·산업(GICS), 국가·통화. → 팩터 중립화·섹터 로테이션.
- **식별자 매핑**: 티커·CUSIP·ISIN·CIK. ← SEC 티커맵 무료.
- **무료 대안**: SEC 티커맵 ✅, GitHub 심볼 목록 ✅, Wikipedia 구성종목, 나스닥/거래소 공시.

## 적법성·리스크 (반드시 준수)

- **MNPI(미공개 중요정보)·개인정보·이용약관**: 대체데이터는 적법 취득·집계·비식별이 전제.
  전문가 네트워크(expert network)는 MNPI 위험(내부자거래 처벌 사례 다수).
- **감쇠·혼잡**: 널리 쓰이면 엣지 소멸(Boyle: 자금이 몰리면 아비트라지는 사라진다).
- **과최적화**: 데이터가 많을수록 거짓 패턴이 많다. 아이디어 우선(Carver), 워크포워드 검증.
- **생존편향·룩어헤드**: 구성종목 이력·발표 시점(as-reported)·지연을 정확히 반영.
