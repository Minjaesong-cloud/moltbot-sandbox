# 한국 시장 일별 데이터 검증 — Naver 금융 API (2026-07 신규)

**돌파구**: `api.finance.naver.com/siseJson.naver` 가 프록시 환경에서 유일하게 뚫린 한국 일별
소스로 확인 (KRX 정보데이터시스템은 차단). 구현: `data/fetch_data.py`의 `naver_daily()`.

| 심볼 | 범위 | 내용 |
|---|---|---|
| KOSPI | **1990-01~현재 일별** | OHLCV (기존 OECD 월별 → 일별로 업그레이드) |
| KOSDAQ | 1996-07~현재 | OHLCV |
| 종목코드 6자리 | 1990년대~ | OHLCV + **외국인소진율(%)** |

## 1. KOSPI 36년 일별 추세 백테스트 (1990-01~2026-07)

| 전략 | CAGR | Sharpe | MaxDD |
|---|---|---|---|
| Buy&Hold | 5.5% | 0.33 | −75.4% |
| **10개월 추세** | **6.9%** | **0.48** | **−45.5%** |
| 추세 + 변동성타깃 10% | 2.4% | 0.34 | −36.9% |

위기 연도 (B&H → 추세):

| 연도 | B&H | 추세 |
|---|---|---|
| 1997 (IMF) | −42.2% | **−9.9%** |
| 2000 (닷컴) | −50.9% | −19.4% |
| 2008 | −40.7% | −22.4% |
| 2020 | +30.8% | +28.1% (상승 유지) |

- **한국은 추세가 CAGR·샤프·MaxDD 셋 다 이기는 드문 시장**이다(보통 추세는 CAGR을 조금
  내주고 DD를 산다). 박스권-급락-급등 반복 구조가 추세 필터와 잘 맞는 것.
- **변동성 타깃의 정직한 비용**: 단독 KOSPI에 10% 볼타깃을 걸면 MaxDD는 −37%로 줄지만
  KOSPI 변동성(20%+)을 계속 절반 이하로 디레버리징해 CAGR 2.4%로 붕괴한다(1998 +39%→+9%).
  볼타깃은 **다자산 포트폴리오의 리스크 균등화**용이지, 단일 고변동 자산의 성과 개선용이 아니다.

## 2. 2026년 7월 라이브 상황 (이 데이터로 본)

KOSPI 2026년: 1월 4,310 → 고점 ~9,100 → **7/20 6,516 (고점 대비 −28.5%, 3주 폭락)**.
- 월별(OECD) 데이터였다면 엔진은 6월 값으로 아직 평온 — **일별 전환의 가치가 즉시 실증됨**:
  추세는 아직 ON(이평선이 랠리 아래에 있음)이지만 변동성 타깃 웨이트가 0.42→**0.15**로
  자동 축소됐다. 스위치(추세)보다 스로틀(볼타깃)이 먼저 반응하는 설계가 작동.

## 3. 외국인소진율 신호 — 약한 순추세, 보조 필터감

종목별 외국인소진율 20일 변화(전일 관측) 5분위 → 이후 20일 수익 (1996~2026):

| 종목 | 최하(매도) | 중간 | 최상(매수) | 상관 |
|---|---|---|---|---|
| 삼성전자 | +3.4% | +0.9~1.8% | **+4.5%** | 0.02 |
| SK하이닉스 | +1.2% | +2.6~2.9% | **+3.2%** | 0.02 |
| 현대차 | +0.8% | +1.0~2.0% | **+3.5%** | 0.07 |
| 네이버 | +1.8% | +0.3~1.6% | **+4.9%** | 0.14 |

- **4종목 전부 "외국인 강한 매수" 분위가 최고 수익** — K-퀀트 통설(외국인 추종)이 약하게
  지지된다. 단 상관 0.02~0.14로 약하고, 삼성전자는 U자형(급매도 후 반등 효과 혼재).
- 판정: **단독 전략 불가, 종목 선정 보조 필터로만**. COT과 같은 3차(포지셔닝) 층위.

## 4. 한국 종목 레벨 횡단면 전략 (24개 대형주, 2000~2026 월간 로테이션)

⚠️ **생존편향 있는 유니버스**: 오늘의 대형주 24개(삼성전자~하나금융)로 과거를 돌렸으므로
**절대 수익률은 부풀려져 있다**. 전략 간 상대 비교(스프레드)가 신뢰할 수 있는 부분.

| 전략 | CAGR | Sharpe | MaxDD |
|---|---|---|---|
| 동일가중 벤치마크 | 14.6% | 0.68 | −38.2% |
| **모멘텀 12-1 상위5** | **21.5%** | 0.73 | −52.9% |
| 모멘텀 하위5 (참고) | 12.4% | 0.53 | −53.9% |
| 저변동성 상위5 | 7.4% | 0.45 | −44.1% |
| 외국인 3개월 순매수 상위5 | 14.8% | 0.65 | −51.5% |
| 모멘텀∩외국인 필터 | 16.2% | 0.61 | −73.1% |
| **듀얼 모멘텀 (상위5 × KOSPI 추세)** | 18.3% | 0.72 | **−33.1%** |

정직한 판정:
- **모멘텀은 한국 대형주에서도 강력**: 상위−하위 스프레드 +9%p/년, 벤치 대비 +7%p.
- **저변동성 이상현상은 한국 대형주에서 실패** (미국 STOCK-LEVEL.md 결과와 정반대).
  이 유니버스의 저변동 종목 = 한전·KT·SKT 등 규제·저성장주 — 팩터의 시장 의존성 실증.
- **외국인 필터는 횡단면 무효**: 시계열(종목별 §3)에선 약한 신호였지만 종목 선택 기준으로는
  벤치 수준이고, 모멘텀과 결합하면 오히려 악화(−73% DD). 승격 불가.
- **실전 권장형은 듀얼 모멘텀**: CAGR 3%p를 내주고 MaxDD를 절반(−53→−33%)으로.
  2022년 전량 현금(0%), 2008년 −21%로 방어. 자산배분 엔진과 같은 원리(절대추세 게이트).
- 미반영: 거래비용·세금(월 로테이션이라 회전율 큼), 배당 제외.

## 남은 한계

- Naver는 비공식 엔드포인트 — 변경·차단 리스크 상존(폴백: OECD 월별, 엔진에 구현됨).
- 가격지수만 있고 배당 미포함(총수익 과소평가, 특히 최근 밸류업 배당 확대 이후).
- 개별 종목 재무(한국)는 여전히 DART API 키 필요 — 팩터 스크리닝은 미국(SEC)만 라이브.
