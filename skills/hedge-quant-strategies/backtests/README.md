# 자산군 전략 백테스트 — 실제 데이터 검증

이 허브의 전략들을 **실제 시장 데이터로 백테스트한 정직한 결과**. finbot 등 실전 시스템에
적용하기 위한 근거·주의사항과 재현 스크립트를 담는다.

## ⚠️ 정직성 원칙 (스킬 자신의 경고를 적용)

이 허브의 전문가들이 반복 경고한다 — **Carver: "과최적화가 최대의 적", Ben Felix: "백테스트의
화려한 성과는 대개 데이터의 인공물"**. 그래서 여기서는:
- **결과를 지어내지 않는다.** 아래는 실제 FRED 데이터로 돌린 진짜 숫자다.
- **과최적화가 적은 강건한 전략만** 검증했다(트렌드추종·리스크패리티·모멘텀은 한 세기·수십
  자산에서 검증된 것으로, "이 산업/종목에 이 전략을 썼더니 대박"식 사후선택과 정반대).
- **한계를 숨기지 않는다**(아래 "한계" 참조).

## 무엇이 검증됐나 (스킬과의 대조)

1. **크라이시스 알파는 실재한다** — 분산 추세추종(CTA)은 2000·2001·2002·2008·2022 **모든 주식
   폭락기에 플랫~소폭**(−1~−5%)이었다. 주식이 −30~−40% 무너질 때. → `trend-following-cta.md`,
   스큐 지도의 "양의 스큐가 위기를 방어한다"가 실제 데이터로 확인.
2. **리스크 패리티의 명성도, 약점도 사실** — 최고 샤프(1.08)·최소 낙폭(−20%)이지만 **2022년
   −15%**(금리 급등에 주식·채권 동반 하락). → `experts/ray-dalio.md`의 논리와 한계 모두 확인.
3. **추세추종은 낙폭을 줄인다** — 주식 200일선 추세가 매수보유의 최대낙폭을 **−78%→−49%**로,
   2008년 손실을 **−41%→−8%**로. 대신 상승장에선 살짝 뒤처질 수 있음(정직한 트레이드오프).
4. **분산의 요체 = 스큐 상보성** — 음의 스큐(주식)만으론 위기에 −40%. 양의 스큐(추세)를 섞으면
   방어된다. → 카탈로그 스큐 지도의 핵심 주장이 실증됨.

## 한계 (반드시 인지)

- **자산군 레벨이지 개별 종목/한국 주식이 아니다.** 이 환경은 FRED만 접근 가능(개별주·KRX 데이터
  차단). 종목 레벨(팩터 랭킹·페어트레이딩)·한국 시장 백테스트는 별도 데이터가 필요 →
  `korea-quant-resources.md`의 도구로 finbot에서 실행.
- **백테스트 불가 전략**: 머저아브·디스트레스트·CDO·액티비스트·구조화크레딧은 딜/신용 데이터가
  필요해 가격 백테스트로 검증 불가. 이들은 논리·손익구조로 평가한다(카탈로그·5단계 프레임).
- **비용 미반영**: 실제로는 거래비용·세금·슬리피지가 수익을 갉아먹는다(특히 회전율 높은 전략).
- **인샘플·생존편향**: 과거가 미래를 보장하지 않는다. Carver의 드로다운 경험칙(최악 = 타깃의
  2배)과 "절반 샤프 사이징"을 실전에 적용하라.
- **오버피팅 주의**: 여기서 파라미터(12개월·200일·60일 변동성)를 데이터에 맞춰 쥐어짜지 않았다.
  표준값을 썼다. finbot에서 파라미터를 최적화하려는 유혹을 경계하라(묵시적 과최적화).

## 종목 레벨 확장

개별 종목(S&P500 2013~2018) 팩터 백테스트(모멘텀·로우볼·리버설·페어)는 `STOCK-LEVEL.md`,
스크립트는 `backtest_stocks.py`. 핵심: 로우볼 이상현상 실증(샤프 1.46), 모멘텀 롱숏은 이 기간
부진(0.12), 인덱스(동일가중 1.33)를 이기기 어려움 — 팩터의 레짐 의존성과 저회전 구현의 중요성 확인.

## 재현

`backtest_assetclass.py` 참조. FRED CSV(무료, 키 불필요)를 받아 위 표를 재생성한다.

## finbot 적용 로드맵

1. **자산군 전략부터**(가장 강건): 분산 추세추종 + 리스크패리티를 코어로. 위 결과가 근거.
2. **종목 레벨 확장**: `korea-quant-resources.md`의 pykrx/퀀터스/젠포트로 한국 팩터 전략
   (밸류·모멘텀·퀄리티) 백테스트. `factor-investing.md`·`experts/ben-felix.md`의 구현품질
   원칙(저회전·섹터상한) 준수.
3. **리스크 관리 우선**: 실패사례(failures-risk-lessons.md)의 체크리스트·Carver 사이징을 코드에.
4. **스큐로 분산**: 음의 스큐(팩터·캐리)에 양의 스큐(추세)를 섞어 위기 방어.
