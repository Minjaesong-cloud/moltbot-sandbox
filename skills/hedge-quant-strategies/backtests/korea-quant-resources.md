# 한국 퀀트 투자·백테스트 자료 (finbot 적용용)

한국 주식(KRX)에 퀀트 전략을 백테스트·자동매매하기 위한 실전 도구·데이터 정리.
(이 리서치 환경은 KRX 데이터가 차단되어 있어, 아래 도구는 finbot/로컬 등 데이터 접근이 되는
곳에서 실행한다.)

## 1. 데이터 수집 (무료·파이썬)

- **pykrx** (github.com/sharebook-kr/pykrx, `pip install pykrx`) — KRX·네이버에서 국내 주식
  OHLCV·시가총액·펀더멘털(PER/PBR/배당)·지수를 스크래핑. 한국 퀀트의 표준 데이터 소스.
  대량 수집은 다소 느림(실시간 스크래핑).
- **FinanceDataReader** — 국내외 주가·지수·환율을 간편히 로드(pykrx 보완).
- **OpenDartReader / DART API** — 전자공시(재무제표) 원천. `financial-statement-analysis`
  스킬(이익의 질·레드 플래그)을 한국 종목에 적용할 때 필수.
- 증권사 오픈API: **키움 REST/OpenAPI, 한국투자증권(KIS) OpenAPI** — 시세·주문(자동매매).

## 2. 백테스팅·자동매매 플랫폼 (노코드/저코드)

- **퀀터스(Quantus, quantus.kr)** — 팩터 기반 백테스트(주식·코인), 리밸런싱·성과측정. 입문에 무난.
- **퀀트킹(QuantKing, quantking.net)** — 백테스트 무제한, 빠른 데이터 업데이트. 팩터 스크리닝 강점.
- **젠포트(Genport, 뉴지스탁)** — 종목선정~매매 전 과정 자동화 로보. **압도적 팩터 수**, 코딩
  없이 전략 작성. **키움·NH투자증권 API로 실전 자동매매 연동**. (뉴지스탁은 DGB금융 계열.)
- 미래에셋 **오토퀀트(AQT)** 등 증권사 자체 서비스도 있음.

## 3. 파이썬 백테스트 프레임워크

- **vectorbt** — 벡터화로 대규모·고속 백테스트(팩터 스크리닝·파라미터 스윕에 강점).
- **backtrader** — 이벤트 기반, 유연한 전략·브로커 시뮬레이션(자동매매 연동에 유리).
- **bt / zipline-reloaded** — 포트폴리오 리밸런싱·자산배분 백테스트.

## 4. 한국 시장 적용 시 주의점 (스킬 원칙과 연결)

- **거래비용·세금이 크다**: 거래세·수수료·슬리피지. 회전율 높은 전략(단기 모멘텀·스탯아브)은
  비용이 수익을 크게 갉아먹는다(Ben Felix의 "구현품질" 원칙: 저회전·섹터상한).
- **유동성·공매도 제약**: 소형주 유동성 얕음, 공매도 규제가 롱숏·페어트레이딩을 제약.
- **생존편향·상장폐지**: 백테스트 유니버스에 상폐 종목을 포함해야 편향이 없다.
- **과최적화 경계**(Carver): 한국 데이터는 미국보다 짧고 표본이 작아 오버피팅 위험이 더 크다.
  파라미터를 데이터에 맞춰 쥐어짜지 말고 표준값·강건성 검증(워크포워드)을 쓴다.
- **재무 검증 결합**: 한국은 지배구조·관계자거래 이슈가 팩터 성과를 왜곡할 수 있다 →
  `financial-statement-analysis`(레드 플래그·M-score)로 저품질 종목을 먼저 걸러라("Eliminate
  first, then investigate", Marcellus).

## 5. finbot 권장 순서

1. **데이터 파이프라인**: pykrx + DART(재무) + 증권사 API(주문) 구축.
2. **강건한 자산군 전략부터**: 한국 지수·국채·달러/원·금으로 추세추종·리스크패리티(../backtests
   결과가 근거). KOSPI+국채+금 3자산 추세추종은 크라이시스 알파의 한국판.
3. **종목 팩터 전략**: 밸류(저 PBR/PER)·퀄리티(고 ROE·저부채)·모멘텀 랭킹. 저회전·섹터중립으로
   구현(factor-investing.md). 상폐 포함·비용 반영 필수.
4. **재무 품질 필터**: M-score·발생액·현금흐름으로 분식 위험 종목 제거 후에만 매수.
5. **리스크 관리 코드화**: Carver 절반 샤프 사이징, 변동성 타깃팅, 최대낙폭 한도, 스큐 분산.
