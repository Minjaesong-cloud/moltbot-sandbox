## 1. 경제 머신 (How the Economic Machine Works)

출발점: **"경제는 복잡해 보이지만 단순한 기계처럼 작동한다."** 30년 넘게 통했고 2008년을
사전에 회피하게 해준 템플릿.

**(1) 거래(Transactions)** — 기계의 기본 부품.
- "An economy is simply the sum of the transactions that make it up." 모든 거래는
  구매자가 **돈 또는 신용**을 상품·서비스·금융자산과 교환.
- 가격 = 총지출 ÷ 판매수량. **총지출이 경제를 움직인다.**
- 최대 거래 주체는 정부: 세금 걷고 쓰는 **중앙정부** + 금리·화폐발행으로 신용량을 통제하는
  **중앙은행**.

**(2) 신용과 부채(Credit & Debt)** — 가장 크고 변동성 크며 가장 오해받는 부분.
- 신용은 대출자·차입자 합의만으로 **무에서 창출**("out of thin air") → 즉시 부채로 전환.
- **신용 ≠ 돈.** 돈은 거래를 즉시 청산하지만, 신용은 **미래 지출을 앞당겨오는 것**
  (pulling spending forward) → 미래엔 반드시 덜 써야 하는 시점이 온다 → 사이클 발생.
- 규모: 미 신용 ≈ **50조 달러** vs 통화 ≈ **3조 달러**. "대부분의 '돈'은 사실 신용이다."
- 힘의 원천: **한 사람의 지출은 다른 사람의 소득.** 소득↑ → 신용도↑ → 차입↑ → 지출↑ →
  타인 소득↑ (자기강화).
- 신용도 2조건: ① 소득 대비 상환능력, ② 담보. 좋은 신용(트랙터=소득 창출) vs 나쁜 신용
  (큰 TV=과소비).

**(3) 3대 힘**
1. **생산성 성장** — 장기 추세선. 변동은 작지만 장기적으로 가장 중요.
2. **단기 부채 사이클** — 약 5~8년, 중앙은행 주도.
3. **장기 부채 사이클** — 약 75~100년.

핵심: **"장기엔 생산성이, 단기엔 신용이 지배한다."** 추세선 위아래 스윙은 신용의 양이 만든다.

## 2. 부채 사이클

**단기(5~8년)**: 신용 주도 지출↑ → 인플레 → 중앙은행 금리↑ → 차입·지출↓ → 소득↓ →
침체 → 금리↓ → 재확장. 매 사이클은 직전보다 더 높은 부채로 끝난다(인간은 갚기보다 더
빌린다) → 장기 부채 누적.

**장기(75~100년)**: 부채가 소득보다 빠르게 쌓임 → 낙관·버블 → 어느 순간 **부채 상환이
소득보다 빠르게 증가** → 지출 삭감 강제 → 역전 = **장기 부채 정점**. 미국 1929, 일본 1989,
미국·유럽 2008 — 모두 같은 이유.

**디레버리징 vs 침체**: 침체는 금리 인하로 해결되지만, 디레버리징은 금리가 이미 0%라
통화정책이 안 통한다. "부채 부담이 너무 커서 반드시 낮춰야 한다."

**디레버리징 4수단**:
1. **긴축**(디플레이션적) — 지출↓ → 소득이 부채보다 더 빨리 줄어 **부담 악화**. 역설적.
2. **부채 축소/디폴트·구조조정**(디플레이션적) — "채권자는 전부 잃느니 일부라도." 그래도
   자산가치가 더 빨리 사라져 부담 악화.
3. **부의 재분배**(디플레이션적) — 세수↓·부양책↑ → 재정적자 폭증 → 부자 증세 → haves vs
   have-nots 갈등 → 사회 무질서(1930년대 → 히틀러·전쟁).
4. **화폐 발행**(인플레이션적) — 중앙은행이 금융자산·국채 매입(2008 연준 2조+). 자산가격↑
   → 그러나 금융자산 보유자만 수혜.

**아름다운 디레버리징**: 디플레 3수단과 인플레 1수단(화폐발행)을 **균형** 배합해, 부채
부담을 낮추면서 디플레 붕괴도 하이퍼인플레도 피하는 상태. 중앙은행(금융자산만 매입 가능)과
중앙정부(화폐 못 찍음)의 **협력**(국채 매입 → 적자 지출)이 필수.

## 3. 빅 사이클 / 세계 질서 변화

**제국·기축통화 흥망**: 지난 500년 최강 제국 10개, 기축통화 3개(길더→파운드→달러, 부상하는
중국). 각 사이클 **약 250년** + 전환기 10~20년(대개 충돌기 — "패권국은 싸우지 않고 물러나지
않는다").

**국력 8대 지표**: ① 교육 ② 발명·기술 ③ 경쟁력 ④ 경제 산출 ⑤ 무역 점유율 ⑥ 군사력
⑦ 금융중심지 ⑧ 기축통화. 인과 순서: 교육 → 혁신 → 경쟁력·무역 → 경제·군사력 → (시차)
기축통화 → 금융중심지. 쇠퇴도 유사 순서.

**"성공 속 쇠퇴의 씨앗"**: 부유해지면 임금↑·경쟁력↓, 덜 일하고 사치·decadent, 싸워서 번
세대 → 물려받은 세대. **기축통화 지위는 필연적으로 과잉 차입을 부른다** — 단기 구매력을
키우지만 장기 재정·통화를 약화.

**빅 사이클 5대 힘**: ① 부채·신용·화폐 사이클 ② 내부 질서/무질서(정치) ③ 외부 지정학
④ 자연(가뭄·홍수·팬데믹 — 역사상 전쟁보다 많이 죽임) ⑤ 인간의 창의성(신기술, 현재 AI —
버블도 유발: 남해 1720, 철도 마니아, 닷컴).

**현재 진단(2025.3 기준)**: WWII 종전부터 **80년째, 후기 사이클 Stage 5**. 과잉 부채 +
내부 분열(포퓰리즘) + 국가 갈등 + 자연재해 + AI. **다자주의 → 단자주의(정글의 법칙)** 전환.
큰 빈부·가치 격차 + 약한 리더십 → 민주정이 3~5년에 걸쳐 독재로 이행하는 역사 패턴 경계.

## 4. 투자 함의 (리스크 패리티/All Weather의 논리)

- 4대 디레버리징 수단이 **디플레 자산과 인플레 자산에 정반대로 작용** → 어느 국면이 올지
  확신할 수 없으므로 **국면별로 상쇄되는 자산을 함께 보유**(리스크 패리티/All Weather의 근거).
  디플레 국면(긴축·부채축소)엔 국채·현금, 인플레 국면(화폐발행)엔 실물·주식·금.
- **매크로 투자자가 볼 지표**: 부채 상환액÷소득, 부채÷소득 추세와 변곡점, 신규 부채 발행
  대비 수요, 기존 부채 자산 보유 의향(뱅크런 선행신호), 금리 0% 하한 도달, 인플레vs디플레
  균형, 국력 8대 지표의 상대 궤적, 빈부격차·정치갈등·지정학 긴장.
- **후기 사이클 tail-risk**(역사적 선례): 자국 부채 매입 압박, 적성국 자산 동결·압류, 만기
  연장·화폐화 디폴트, 몰수적 과세, 자본·외환 통제.

## 5. 핵심 규칙 · 수치

**규칙**:
1. **부채 지속가능성**: 부채는 소득보다 빠르게 늘어선 안 된다. 상환 증가율 > 소득 증가율이
   되는 순간이 정점.
2. **신용의 질**: 소득 창출처(트랙터)엔 좋고, 과소비(TV)엔 나쁘다. 부채는 스스로를 갚아야.
3. **신용도**: ① 소득 대비 상환능력 ② 담보가 있을 때만 건전.
4. **디레버리징 균형**: 디플레 3 vs 인플레 1을 균형 배합해야 "아름다운 디레버리징".
5. **정책 역할 분담**: 중앙은행=금융자산만 매입, 중앙정부=상품·서비스 매입하되 화폐 못 찍음
   → 부양엔 양자 협력 필수.
6. **모델은 timeless & universal**해야. 못 설명하는 큰 사건이 있으면 빠진 변수가 있는 것.

**수치·주기**: 단기 부채 사이클 5~8년(~6년±3) / 장기 75~100년(빅사이클 ~80년±25) /
제국 빅사이클 ~250년, 전환기 10~20년 / 민주→독재 3~5년 / 미 신용 50조 vs 통화 3조 /
2008 연준 2조+ / 금리 0% 하한(1930s·2008) / 현재 WWII+80년 Stage 5.
