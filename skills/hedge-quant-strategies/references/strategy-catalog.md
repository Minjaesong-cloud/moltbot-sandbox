# 헤지펀드·퀀트 전략 종합 카탈로그

세계 헤지펀드·체계적 투자 전략을 업계 표준 분류(HFR/HFRI, Credit Suisse, 학술 문헌)에
따라 빠짐없이 정리한 마스터 인덱스. 각 전략은 **수익원(엣지) / 손익구조(스큐) / 주요 리스크 /
캐파시티 / 대표 사례**로 요약한다. 심화는 `hedge-fund-strategies.md`, `quant-strategies.md`,
`factor-investing.md`를 참조.

> 사용법: 어떤 전략이든 SKILL.md의 5단계 평가 프레임("엣지의 원천? 손익구조? 캐파? 리스크?
> 비용?")으로 분해한다. 수치는 자릿수 이해용 예시다.

핵심 분류(8대 패밀리): ① 주식 롱숏 ② 이벤트 드리븐 ③ 상대가치·차익거래 ④ 글로벌 매크로
⑤ 매니지드 퓨처스/CTA ⑥ 크레딧 ⑦ 퀀트/체계적 ⑧ 멀티전략·기타.

---

## ① 주식 (Equity) 전략

**롱숏 에쿼티(Long/Short Equity)** — 저평가 롱 + 고평가 숏. 순노출(net exposure) 조절로
시장 베타 일부 유지. 엣지=종목선택(알파). 스큐=대체로 대칭, 숏스퀴즈 꼬리. 캐파=크다.
가장 흔한 전략. → 상세 hedge-fund-strategies.md.

**에쿼티 마켓 뉴트럴(Equity Market Neutral)** — 롱=숏으로 베타를 0에 맞춤. 순수 종목선택.
엣지=상대가치·팩터. 스큐=낮은 변동성. 리스크=팩터 노출 잔차·레버리지. HFRX EMN 지수는
1997~ 거의 횡보(냉정한 현실).

**숏 바이어스 / 데디케이티드 숏(Dedicated Short Bias)** — 구조적 순숏. 회계부정·과대평가
공략. 엣지=상세 리서치. 스큐=음(시장 상승 드리프트에 역행, HFRX 16년 연 -10~11%).
리스크=무한손실·숏스퀴즈. 캐파=작다.

**펀더멘털 밸류/그로스** — DCF·comparables 기반 기업가치 vs 시장가 괴리. 롱온리 또는 롱숏.
엣지=밸류/퀄리티 팩터·정보우위. 스큐=밸류는 장기 부진 위험.

**섹터 특화(Sector-focused)** — 헬스케어·테크·금융·에너지 등 특정 섹터 전문. 엣지=도메인
전문성. 리스크=섹터 집중·규제. 예: 바이오텍 롱숏(임상 이벤트).

**퀀트 에쿼티(Quantitative Equity)** — 팩터·통계 모델로 수백~수천 종목 롱숏. → 퀀트 패밀리
및 factor-investing.md.

**액티비스트(Activist)** — 지분 매집 후 경영개입(이사회·자사주·분할)으로 가치 변화 유도.
엣지=지배구조 개선·촉매. 스큐=집중·장기·유동성 낮음. 리스크=경영권 분쟁. 예: Elliott, Icahn.

**130/30·익스텐션** — 100% 롱 + 30% 숏 + 30% 추가 롱. 롱온리에 제한적 숏을 얹어 알파 확장.

## ② 이벤트 드리븐(Event-Driven) 전략

**머저 아비트라지 / 리스크 아비트라지** — M&A 발표 후 타깃가와 인수가 사이 스프레드 수취,
딜 브레이크 리스크 부담. 엣지=딜 성사 판단. 스큐=**숏풋 유사(음의 스큐)** — 평시 안정,
하락장 손실. 캐파=제한적. → 상세 hedge-fund-strategies.md(현금/주식 딜, 9대 리스크 요인).

**디스트레스트(Distressed Securities)** — 부실·파산 기업의 채권·주식을 저가 매입, 구조조정·
회생·청산에서 회수. 엣지=법적·재무 분석, 워크아웃 전문성. 스큐=유동성 낮음·장기. 리스크=
회생 실패·소송. 예: Elliott, Oaktree.

**스페셜 시추에이션(Special Situations)** — 스핀오프·분할·자산매각·자본재편·소송 등 촉매 이벤트.
엣지=복잡성 프리미엄·구조 분석. 유연한 롱숏·자본구조 전반.

**캐피털 스트럭처 아비트라지** — 같은 기업의 주식 vs 채권 vs CDS 간 상대가치. 주식=콜, 부채=
숏풋(옵션이론). **부실 구간에서만 헤지비율이 안정적** → 평시엔 수익 없는 리스크. → hedge-fund-strategies.md.

**리스크/PIPE·Reg D** — 상장사에 사모 투자(할인 발행·전환권). 엣지=유동성·구조 프리미엄.

**액티비스트(이벤트형)** — 위 ①과 겹침, 촉매를 스스로 만드는 이벤트 전략으로도 분류.
→ 이벤트드리븐·액티비스트 플레이북 상세 `activist-event-driven.md`.

## ③ 상대가치 · 차익거래(Relative Value / Arbitrage)

핵심: 서로 연관된 두 자산의 가격 괴리에 **수렴** 베팅. 대개 레버리지 의존 → 꼬리 리스크(LTCM).
"진짜 아비트라지는 자금이 몰려 소멸한다" — 이름의 arbitrage는 무위험이 아니다.

**픽스드 인컴 아비트라지** — 채권 간 미세 괴리. 하위 유형:
- On-the-run/Off-the-run(유동성 프리미엄), 스왑 스프레드, 일드커브(버터플라이), TED 스프레드,
  국채 baseis(현물 vs 선물). 엣지=미세 미스프라이싱. **20:1+ 초고레버리지** 필요 → 스트레스 시
  파멸(LTCM). 스큐=음(매끈하다 대참사).

**컨버터블 아비트라지** — 전환사채 매수 + 주식/채권/옵션 헤지로 싼 옵셔널리티 추출. 캐파=제한적
(싼 CB가 한정). 예: Ken Griffin(Citadel) 초기. → hedge-fund-strategies.md.

**볼래틸리티 아비트라지** — 내재변동성 vs 실현변동성 괴리 매매(델타뉴트럴). 하위: 디스퍼전
(지수 볼 vs 개별주 볼), 감마 스캘핑, 볼 서페이스 상대가치. 스큐=블랙스완 때 급락. → options-derivatives.

**스탯 아브 / 페어트레이딩** — 통계적 종목쌍/바스켓의 평균회귀. 다수 소액 베팅. → quant-strategies.md.

**MBS/ABS 아비트라지** — 모기지·자산유동화증권의 상대가치·프리페이먼트 모델링. 리스크=모델·유동성
(2008). 예: 초기 스탯아브 계보.

**뮤니(지방채) 아비트라지** — 지방채 vs 과세채/스왑 간 세후 상대가치·레버리지.

**인덱스 아비트라지** — 지수선물 vs 구성종목 바스켓. 거의 무위험 → 수익이 무위험이자율로 수렴,
HFT·IB만. → hedge-fund-strategies.md.

**베이시스 트레이드** — 현물-선물, 캐시-CDS 등 두 형태 간 베이시스. 국채 basis 트레이드는
헤지펀드의 레버리지 취약점(반복 규제 이슈).

## ④ 글로벌 매크로(Global Macro)

거시 변수(금리·환율·원자재·주가지수)에 방향성/상대가치 베팅. 톱다운.

**재량적 매크로(Discretionary)** — 매니저 판단. 엣지=거시 분석·정책 예측. 예: Soros(1992 GBP,
하루 $10억), Druckenmiller, Bridgewater(재량+체계 혼합). 스큐=다양, 유연.

**시스템적 매크로(Systematic Macro)** — 모델 기반 거시 신호. 캐리·밸류·모멘텀을 자산군 전반에.

**통화(FX)** — 캐리트레이드(고금리 통화 롱/저금리 숏, 스큐=음), 밸류(PPP), 모멘텀.

**금리/채권 방향성** — 듀레이션·커브·국가 간 금리차 베팅.

**이머징 마켓 매크로** — 신흥국 통화·채권·주식. 리스크=특이(정치·자본통제) 사건에 크게 노출.
→ 상세 `emerging-macro.md`.

**커모디티 매크로** — 원자재 방향성·기간구조(콘탱고/백워데이션)·상대가치.

Dalio의 부채·빅 사이클 프레임(references/experts/ray-dalio.md)이 매크로 국면 판단의 대표 틀.

## ⑤ 매니지드 퓨처스 / CTA

파생(선물·옵션·스왑)만 매매 → CFTC 규제. 주식과 저상관, 위기 시 **Crisis Alpha**.

**트렌드추종(Trend Following / Time-Series Momentum)** — 최근 오른 것 롱·내린 것 숏, 자산군
전반. 엣지=추세 지속. 스큐=**양(작은 손실 다수 + 가끔 큰 수익)**. 예: AHL/Winton, Aspect,
Man, Millburn. → 상세 `trend-following-cta.md`.

**카운터트렌드 / 평균회귀** — 추세추종의 반대, 단기 반전 포착.

**단기 시스템(Short-term Systematic)** — 일중~수일 신호. 캐파 작고 거래비용 민감.

**펀더멘털 시스템(Systematic Fundamental)** — 거시·재무 데이터 기반 규칙(예: 캐리, 밸류).

**캐리 전략** — 수익률 곡선·통화·원자재의 "보유수익"이 높은 자산 롱. 스큐=음(평시 꾸준, 위기 급락).

## ⑥ 크레딧(Credit) 전략

**롱숏 크레딧** — 회사채·CDS 롱숏. 엣지=신용분석·상대가치.

**디스트레스트 크레딧** — ②와 겹침, 채권 중심.

**구조화 크레딧(Structured Credit)** — MBS·ABS·CLO·CDO 트랜치 매매. 엣지=구조·상관 모델링.
리스크=상관 동조화·모델(2008). → 상세 `structured-credit.md`, 상품은 options-derivatives의 credit-swaps.md.

**크레딧 상대가치** — 캐피털 스트럭처, CDS-채권 베이시스, 인덱스-싱글네임.

**다이렉트 렌딩 / 프라이빗 크레딧** — 비상장 사기업 대출. 마크투마켓 회피 → **volatility
laundering** 논쟁(Ben Felix). 유동성·adverse selection 리스크. → references/experts/ben-felix.md.

**컨버터블·하이일드** — 전환사채·고수익채 중심.

## ⑦ 퀀트 / 체계적(Quant / Systematic)

패밀리 전반을 관통. 상세 quant-strategies.md, factor-investing.md.

**팩터 투자** — 밸류·모멘텀·퀄리티·사이즈·로우볼·캐리에 체계적 노출. 스마트베타의 토대.
구현품질(회전·섹터상한)이 노출만큼 중요(Ben Felix). → factor-investing.md, experts/ben-felix.md.

**통계적 차익거래** — 미세 이상현상의 통계적 포착(Niederhoffer 계보).

**페어트레이딩** — 공적분 종목쌍 평균회귀(Bamberger→Frey→RenTech). → 상세 `statistical-arbitrage.md`.

**고빈도 매매(HFT) / 마켓메이킹** — 유동성 공급으로 스프레드 수취. 엣지=속도·인프라. 캐파=작다.

**머신러닝 / 대체데이터(Alt-data)** — 위성·신용카드·웹 데이터로 알파. 리스크=과최적화(López de
Prado). 백테스트 신뢰성 문제.

**리스크 패리티(Risk Parity)** — 자산군별 리스크 기여를 균등화(주식이 아니라 리스크로 분산),
레버리지로 목표변동성 달성. 국면 불확실성 대비. 예: Bridgewater All Weather. → experts/ray-dalio.md.

**변동성 타깃팅 / 매니지드 볼** — 실현변동성에 따라 익스포저 조절.

**옵션·변동성 전략** — 디스퍼전, 감마 스캘핑, 볼 아비트라지, 테일 헤지. → 상세
`volatility-strategies.md`, 그릭스·프라이싱은 자매 스킬 options-derivatives.

**시계열 모멘텀** — ⑤ CTA와 겹침, 퀀트 관점의 핵심 프리미엄.

## ⑧ 멀티전략 · 기타

**멀티전략(Multi-Strategy)** — 여러 전략을 한 펀드에서 자본을 동적으로 배분. 팟(pod) 구조로
매니저별 리스크 한도. 예: Citadel, Millennium, Point72, Balyasny. 엣지=분산+자본 재배분.
→ 상세 `multi-strategy-pods.md`.

**펀드 오브 펀즈(FoF)** — 여러 헤지펀드에 분산 투자. 이중 수수료·Madoff 스캔들로 쇠퇴.

**테일 리스크 헤징** — 꼬리 위험(급락) 보호를 상시 매입. 평시 비용(음의 캐리), 위기 시 큰 수익.
예: Universa(Taleb 자문).

**인슈어런스 링크드 / 캣본드(ILS)** — 자연재해 리스크. 주식·채권과 무상관(진짜 분산). 리스크=
대재해.

**크립토 / 디지털자산** — 현물-선물 베이시스, 펀딩레이트 차익, 마켓메이킹, 온체인. 리스크=
카운터파티·규제·해킹(FTX). → 상세 `crypto-digital-asset.md`.

**로보/양적 배분, 위험균형 TDF 등** — 규칙 기반 자산배분(퀀트와 전통 자산운용의 경계).

## 손익구조(스큐)로 본 전략 지도 — 답변 시 핵심 직관

- **음의 스큐(평시 꾸준·가끔 대손실)**: 머저아브, 캐리(FX·채권), 숏볼/볼셀링, 픽스드인컴아브,
  컨버터블아브, 대부분의 "수렴" 아비트라지. → "숏풋 파는 것과 유사", 레버리지·상관에 취약.
- **양의 스큐(잦은 소손실·가끔 대수익)**: 트렌드추종/CTA, 테일 헤지, 롱볼, 롱 옵션. → 위기 방어.
- **대체로 대칭**: 롱숏 에쿼티, 마켓뉴트럴, 페어트레이딩(단, 영구 괴리 꼬리).
