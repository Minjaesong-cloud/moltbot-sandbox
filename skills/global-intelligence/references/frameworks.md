# 분석틀 (durable) — 국제정세·금융·경영·AI를 보는 법

빨리 바뀌는 "현재 상황"이 아니라, 변하지 않는 **분석 방법**. 확립된 프레임워크와 이미 추출한
전문가 렌즈(Dalio·Marks·Druckenmiller — `hedge-quant-strategies/references/experts/`)를 연결한다.
세부 인사이트는 `skill-autoupdate`가 신뢰 채널(GZERO·Zeihan·HBR 등)에서 주간 갱신한다.

## 1. 국제정세·지정학 분석틀

핵심 질문 순서 (뉴스에 휘둘리지 않고 구조를 보는 법):
1. **구조적 요인 vs 사건**: 인구·지리·자원·동맹 같은 느린 구조(Zeihan의 렌즈)와 그날의
   사건을 분리. 구조가 방향을, 사건이 타이밍을 만든다.
2. **행위자의 이해관계**: 각국이 무엇을 얻으려는가(안보·자원·체제 정당성). "누가 왜"가 출발점.
3. **에스컬레이션 사다리**: 지금 어느 단계인가(수사→제재→대리전→직접충돌). 되돌릴 수 있는가.
4. **시장·경제 전이 경로**: 정세가 어떻게 자산가격으로 오는가(에너지·공급망·안전자산·환율).
   → 여기서 `hedge-quant-strategies`(매크로·리스크)와 `industry-analysis`(산업 영향)로 연결.

주의: 지정학 분석은 **확률이지 예언이 아니다.** 단정·확신 어조를 경계(Marks의 2차적 사고).

## 2. 국제금융·글로벌 매크로 분석틀

**4대 축** (Dalio의 경제 머신 + 표준 매크로):
- **성장**(경기 사이클 어디인가) · **인플레이션**(방향과 기대) · **정책**(중앙은행 완화/긴축) ·
  **유동성**(신용·달러·자금흐름 — Druckenmiller의 렌즈).
- **부채 사이클**(Dalio): 단기(경기)와 장기(부채 누적·디레버리징) 두 사이클을 겹쳐 본다.
- **전이**: 금리→환율→원자재→신용스프레드→주식. `live_brief.py macro`로 이 지표들을 실시간
  확인(10Y·2Y·스프레드·달러·유가·VIX·하이일드).

실시간 데이터는 이미 프로그램 조회 가능: `hedge-quant-strategies/data/fetch_data.py`
(FRED·IMF·World Bank·ECB·BIS). 시황 해석은 신뢰 소스(FT·IMF·Fed) 라이브 조회.

## 3. 국제경영·전략 분석틀

- **산업 구조**(Porter 5 Forces) + 실측 경제성(마진·ROE·자본집약도) → `industry-analysis` 스킬.
- **전략 프레임**(HBR·McKinsey·BCG의 확립된 도구): 경쟁우위 원천, 규모·범위의 경제,
  수직계열화(→ `elon-musk-insights`의 "공장이 제품"), 파괴적 혁신.
- **글로벌 확장**: 규제·문화·환율·공급망 리스크. 국가 리스크는 `damodaran.erp`(국가 ERP).

## 4. AI 최신 기능·활용법 추적틀

- **1차 소스 우선**: 기능·API는 공식 문서(Anthropic·OpenAI·DeepMind)가 근거. 유튜버 요약보다
  공식 발표를 먼저 확인(과장·오해 차단).
- **"발표 vs 실사용" 구분**: 데모와 실제 성능은 다르다. AI Explained의 벤치마크식 검증 관점,
  Simon Willison의 재현 가능한 how-to를 신뢰.
- **활용법**: 새 기능이 나오면 "무엇이 실제로 가능해졌나 / 어디에 쓰나 / 한계는"을 물어
  실무 적용. 기술 원리는 `ai-engineering` 스킬.
- 최신 발표는 저장하지 말고 조회(`live_brief.py ai` 또는 공식 블로그 라이브 fetch).

## 관통 규율

- **구조(durable)와 현재(live)를 분리**한다. "어떻게 분석하나"는 여기, "지금 어떤가"는 실시간.
- 모든 live 결과에 **조회 시각·출처** 표기. 저장된 요약을 최신인 척하지 않는다.
- 확률적 판단, 반대 시나리오 병기(Marks·Dalio의 겸손). 단정 회피.
