# 글로벌 인텔리전스 — 국제정세·금융·경제·경영·AI 팔로우업

빨리 바뀌는 분야를 신뢰 소스 기반으로 따라잡는 스킬. 자매 스킬 `hedge-quant-strategies`
(전략·투자), `industry-analysis`(산업), `ai-engineering`(AI 기술)과 연결된다.

## ⚠️ 제1원칙 — 저장된 요약을 "최신"인 척하지 않는다

이 스킬의 핵심 규율. 국제정세·시황·최신 AI 기능은 **매일 바뀐다.** 그래서:
- **변하지 않는 것(분석틀·방법론·구조적 사실)만 references에 저장**한다.
- **현재 상황(속보·시황·최신 기능)은 물어보는 시점에 신뢰 소스에서 실시간 조회**한다.
  미리 저장한 요약은 낡는 순간 거짓이 되므로, "지금 어떤가"에는 반드시 live fetch로 답한다.
- 인기≠신뢰. `references/sources.md`의 검증된 소스만. 근거 없는 예측·단정 금지.

## 두 층 구조

### 층 1 — Durable (저장·주간 갱신)
분석틀·프레임워크·구조적 지식. `skill-autoupdate`가 신뢰 유튜브 채널에서 주간 갱신.
- 4개 도메인 분석틀(지정학·매크로·경영·AI 추적법) → `references/frameworks.md`
- 신뢰 소스 등록부(도메인별 검증 소스) → `references/sources.md`

### 층 2 — Live (실시간 조회)
"지금 상황"은 저장하지 않고 조회한다. `live_brief.py`로 신뢰 소스를 실시간 fetch.

```bash
python live_brief.py geopolitics   # 국제정세 최신
python live_brief.py macro         # 글로벌 매크로·시황
python live_brief.py ai            # 최신 AI 기능·발표
```

또는 대화 중 최신이 필요하면 Firecrawl/WebSearch로 `references/sources.md`의 신뢰 소스를
직접 조회한다(속보성 질문에는 항상 이 경로).

## 표준 워크플로

1. **질문이 "구조·방법"인가 "현재 상황"인가** 판별.
   - 구조·방법("지정학 리스크를 어떻게 보나") → references(층 1).
   - 현재 상황("지금 중동 정세", "이번 주 Fed") → live fetch(층 2), 조회 시각 명시.
2. **투자 연결**: 정세→전략은 `hedge-quant-strategies`(매크로·Dalio·Druckenmiller), 산업
   영향은 `industry-analysis`와 엮는다.
3. **출처·시점 명시**: live 조회 결과는 "언제 기준"인지 반드시 표기.

## 갱신

`skill-autoupdate`에 이 스킬의 신뢰 유튜브 소스가 등록되면 durable 층이 주간 자동 갱신된다.
live 층은 갱신이 아니라 매 조회가 최신 — 저장하지 않는 것이 규율이다.
